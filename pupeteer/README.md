# Kohai Godot LiveLink
python main.py --port 5555
Godot RemoteSkeletonUDP(udp_port=5555) → INSTANT mocap

Opciones:
--host 127.0.0.1     # Dirección IP del host
--port 5555          # Puerto UDP
--video input.mp4    # Archivo de video
--demo               # Demo sintético
--ascii              # Renderizar ASCII skeleton

Hotkeys:
SPACE → pause/resume
C → calib height
Q → quit
