# Claude Entry Point For Odisea

Leer primero `AGENTS.md`. Luego usar:

- `docs/agents/README.md` para el mapa comun de agentes.
- `docs/agents/tooling.md` para tests, eval headless, telemetria, props y UI.
- `docs/agents/skills-index.md` para encontrar skills/comandos.
- `.claude/skills/` solo cuando Claude necesite una skill nativa especifica.

No inventar reglas locales aqui. Si una regla aplica a todos los agentes, va en `AGENTS.md`
o en `docs/agents/`.
