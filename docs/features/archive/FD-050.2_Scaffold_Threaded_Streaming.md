# FD-050.2 — Scaffold WFC en Thread + Streaming Infinito

**Parent:** FD-050 — Pasarelas y Andamios Procedurales (WFC 2D)  
**Status:** Spec  
**Scope:** Acto I — Gap casco-espirales  
**Branch:** `fd-050-scaffold-wfc-17347442582962886612`

---

## Problema

Actualmente `ScaffoldWFCGenerator` corre todo en el thread principal:
1. WFC solver (hasta 400 retries, constraint propagation completa)
2. Validación de height alignment
3. Instanciación de todos los módulos de una vez (`_instance_grid`)

Esto causa:
- **Lag en el main thread** durante la generación (aunque sea breve con grids chicos)
- **Spike de instanciación** al crear ~24 `SteelGratePlatform` nodes con `_rebuild()` en un solo frame
- **Grid finito** — no escala para el gap casco-espirales completo

## Objetivo

Convertir el generador en un sistema de **streaming infinito** que:
1. Resuelve WFC en background thread → cero lag en main thread
2. Instancia módulos progresivamente (N por frame) → sin spikes
3. Soporta expansión bajo demanda (nuevas grillas adyacentes) → mundo infinito

---

## Arquitectura

### Fase 1 — Threaded WFC solver

```
Main Thread                    Background Thread
    |                                |
    |-- spawn thread --------------->|
    |   (seeds, params, grid dims)   |
    |                                |-- _wfc_attempt() × N retries
    |                                |-- _validate_height_alignment()
    |                                |-- _prune_disconnected_components()
    |                                |
    |<-- signal: generation_done ----|
    |   (Array[CellState])           |
    |                                |
    |-- _instance_grid_streamed()    |
```

**Nuevo archivo:** `core_v2/systems/ScaffoldWFCThreaded.gd`

```gdscript
extends Node
class_name ScaffoldWFCThreaded

signal generation_done(grid_data)
signal generation_failed()
signal chunk_ready(chunk_data)

var _thread: Thread = null
var _mutex: Mutex = null
var _semaphore: Semaphore = null
var _pending_grids: Array = []
var _should_exit: bool = false

func request_grid(params: Dictionary) -> void:
    # params: grid_width, grid_depth, cell_size, seed, weights...
    _pending_grids.append(params)
    if _thread == null or not _thread.is_active():
        _start_worker()

func _start_worker() -> void:
    _should_exit = false
    _thread = Thread.new()
    _thread.start(self, "_worker_loop")

func _worker_loop(_userdata) -> void:
    while not _should_exit:
        if _pending_grids.empty():
            OS.delay_msec(16)  # ~60fps polling
            continue
        var params = _pending_grids.pop_front()
        var generator = _create_generator(params)
        var grid = generator._wfc_generate()
        if grid.empty():
            call_deferred("emit_signal", "generation_failed")
        else:
            call_deferred("emit_signal", "generation_done", grid)

func _create_generator(params: Dictionary) -> ScaffoldWFCGenerator:
    var gen = ScaffoldWFCGenerator.new()
    gen.grid_width = params.get("grid_width", 6)
    gen.grid_depth = params.get("grid_depth", 4)
    gen.cell_size = params.get("cell_size", 10.0)
    gen.map_seed = params.get("seed", -1)
    # ... transferir todos los weights y params
    return gen

func stop() -> void:
    _should_exit = true
    if _thread:
        _thread.wait_to_finish()
```

**Nota Godot 3:** `Thread.new()` existe en Godot 3. `call_deferred("emit_signal", ...)` es seguro para comunicar del worker al main thread.

### Fase 2 — Instanciación progresiva

En vez de instanciar 24 módulos en un frame:

```gdscript
var _instance_queue: Array = []
var _instances_per_frame: int = 4
var _current_grid: Array = []

func _on_generation_done(grid: Array) -> void:
    _current_grid = grid
    _build_instance_queue()

func _build_instance_queue() -> void:
    _instance_queue.clear()
    for y in range(grid_depth):
        for x in range(grid_width):
            var state = _current_grid[_idx(x, y)]
            if state != null and state.variant.id != "EMPTY":
                _instance_queue.append({"x": x, "y": y, "state": state})

func _process(_delta) -> void:
    if _instance_queue.empty():
        set_process(false)
        return
    var count = 0
    while count < _instances_per_frame and not _instance_queue.empty():
        var entry = _instance_queue.pop_front()
        _instance_one(entry.x, entry.y, entry.state)
        count += 1
```

Esto distribuye la creación de nodos + `_rebuild()` en varios frames, eliminando el spike.

### Fase 3 — Expansión bajo demanda (streaming infinito)

El generador actual produce una grilla finita (ej: 6×4). Para el gap casco-espirales necesitamos grillas adyacentes que se generen cuando el jugador se acerca al borde.

```
Grilla A (6×4)     Grilla B (6×4)     Grilla C (6×4)
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│             │    │             │    │             │
│    activa   │───→│  cargando   │───→│  pendiente  │
│             │    │             │    │             │
└─────────────┘    └─────────────┘    └─────────────┘
  jugador aquí       siguiente          pre-carga
```

**Componente StreamController:**

```gdscript
extends Spatial
class_name ScaffoldStreamController

export(float, 20.0, 200.0) var load_radius := 60.0
export(float, 20.0, 200.0) var unload_radius := 90.0
export(int, 4, 12) var chunk_width := 6
export(int, 2, 8) var chunk_depth := 4

var _active_chunks: Dictionary = {}  # Vector2(chunk_x, chunk_z) -> Node
var _chunk_pool: Array = []
var _threaded_generator: ScaffoldWFCThreaded

func _ready() -> void:
    _threaded_generator = ScaffoldWFCThreaded.new()
    add_child(_threaded_generator)
    _threaded_generator.connect("generation_done", self, "_on_chunk_generated")

func _process(_delta) -> void:
    var player_pos = _get_player_position()
    var player_chunk = _world_to_chunk(player_pos)
    
    # Request new chunks in load_radius
    for cx in range(player_chunk.x - 2, player_chunk.x + 3):
        for cz in range(player_chunk.y - 2, player_chunk.y + 3):
            var chunk_key = Vector2(cx, cz)
            if _active_chunks.has(chunk_key):
                continue
            if _is_in_radius(chunk_key, player_chunk, load_radius):
                _request_chunk(chunk_key)
    
    # Unload distant chunks
    for key in _active_chunks.keys():
        if not _is_in_radius(key, player_chunk, unload_radius):
            _unload_chunk(key)

func _request_chunk(chunk_key: Vector2) -> void:
    var seed_base = 42  # global seed
    var chunk_seed = hash(chunk_key.x * 73856093 + chunk_key.y * 19349663 + seed_base)
    var params = {
        "grid_width": chunk_width,
        "grid_depth": chunk_depth,
        "cell_size": 10.0,
        "seed": chunk_seed
    }
    _threaded_generator.request_grid(params)

func _on_chunk_generated(chunk_data) -> void:
    # Instance chunk at world position
    # Connect edge cells to adjacent chunks
    pass
```

**Constraint de borde entre chunks:** Las celdas del borde de un chunk deben respetar las conexiones del chunk adyacente ya generado. Esto requiere:
- Guardar el estado del borde de cada chunk generado
- Pasarlo como boundary constraint al chunk nuevo
- El WFC solver ya soporta boundary constraints via `_apply_boundary_constraints`

## Plan de implementación

### Step 0: Cache de grids por seed + params (~5 min)

Capa mínima, sin romper nada. Ideal para iteración rápida en editor.

```gdscript
# En ScaffoldWFCGenerator
var _grid_cache: Dictionary = {}

func generate(seed_val: int = -1):
    var cache_key = _make_cache_key(seed_val)
    if _grid_cache.has(cache_key):
        print("[ScaffoldWFC] Cache hit: ", cache_key)
        _instance_grid(_grid_cache[cache_key])
        return
    
    # ... WFC solver existente ...
    var grid = _wfc_generate()
    if not grid.empty():
        _grid_cache[cache_key] = grid.duplicate(true)
        _instance_grid(grid)

func _make_cache_key(seed_val: int) -> String:
    return "s%d_w%d_d%d_c%.1f" % [seed_val, grid_width, grid_depth, cell_size]

func clear_cache() -> void:
    _grid_cache.clear()
```

**Beneficio:** cada combinación (seed + dimensiones) se resuelve una sola vez. Regenerar en editor es instantáneo. Base para chunks después (cada chunk es un cache entry con key = chunk_coord + seed).

### Step 1: Separar solver de instanciación
- Extraer `_wfc_generate()` como función pura (sin side effects de escena)
- Mover `_instance_grid()` al componente que maneja el main thread
- El generator devuelve solo datos (`Array[CellState]`)

### Step 2: Threaded wrapper
- Crear `ScaffoldWFCThreaded` con `Thread`
- Comunicación via `call_deferred` + signals
- Test: generar grid en thread y verificar que main thread no se bloquea

### Step 3: Instanciación progresiva
- `_process` consume una cola de instanciación
- `_instances_per_frame` configurable
- Test: medir frame time durante instanciación

### Step 4: Streaming infinito
- `ScaffoldStreamController` con lógica de chunks
- Boundary constraints entre chunks adyacentes
- Pool de chunks para reciclar nodos

## Criterios de aceptación

- [ ] `ScaffoldWFCGenerator._wfc_generate()` es side-effect free (no toca escena)
- [ ] `ScaffoldWFCThreaded` resuelve en background sin bloquear main thread (< 1ms en main thread)
- [ ] Instanciación progresiva mantiene 60fps (máx 4-6 módulos/frame)
- [ ] `ScaffoldStreamController` genera chunks adyacentes al aproximarse el jugador
- [ ] Conexiones entre chunks son consistentes (borde de chunk A matchea borde de chunk B)
- [ ] Memoria controlada: chunks lejanos se liberan
