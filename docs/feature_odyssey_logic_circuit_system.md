Technical Specification: Odyssey Logic Circuit System (OLCS) ​1. Objective ​Implement a node-based visual scripting environment (similar to AnimationTree) within the editor to define logic connections between InteractableV2 objects. The system must support dynamic visual representation of connections (Cables vs. WiFi) and destructible connectivity mechanics. ​2. Architecture Overview ​The system consists of three pillars: ​The Graph Resource: Stores the topology of the logic. ​The Manager Node: Executes the logic deterministically. ​The Cable Generator: Procedurally generates geometry for physical connections. ​3. Core Components ​A. LogicCircuitManager (Node) ​The brain of the local system. Placed in the scene root. ​Exports: ​circuit_data: CircuitGraphResource (The saved graph). ​auto_build_cables: bool (Triggers procedural generation in editor). ​Responsibility: ​In step(dt), it propagates signals from Sources (Levers) to Receivers (Doors) based on the graph. ​Handles the state of connections (e.g., if a cable is cut). ​B. CircuitGraphResource (Resource) ​Stores the node graph structure. ​Data Structure: Dictionary containing: ​nodes: Array of node references (NodePaths relative to Manager). ​connections: Array of structs { from: "node_A", to: "node_B", type: "WIRED", points: [Vector3] }. ​C. CircuitCable (Generated Node) ​A procedural object generated at runtime (or baked in editor). ​Components: ​Path: Defines the curve between objects. ​CSGPolygon (mode Path): The visual rubber/metal coating. ​HurtboxV2 (Area): Allows the cable to be severed by damage. ​Logic: If health <= 0, it emits connection_broken to the Manager. ​4. The Visual Editor (Plugin Implementation) ​We will create a Godot Editor Plugin to edit CircuitGraphResource. ​GUI UX (The "Board") ​A GraphEdit control that appears in the bottom panel when LogicCircuitManager is selected. ​Node Types ​Prop Node: Represents a scene object (e.g., "Lever_01"). ​Inputs: set_active, toggle. ​Outputs: activated, deactivated. ​Logic Gate: AND, OR, XOR, DELAY. ​Connection Edge (The Line): ​Clicking a connection line opens a Property Popup: ​Connectivity Type: Dropdown [ Wireless (WiFi), Wired (Cable) ]. ​Cable Material: Dropdown [ Industrial, Insulated, Exposed ]. ​Slack: Float (Catenary curve tension). ​5. Cable Generation Algorithm (The "Path Ideal") ​When "Wired" is selected, the LogicCircuitManager calculates the path using a Manhattan-style Routing or Catenary Curve. ​Algorithm: generate_cable_path(start_node, end_node, slack) ​Anchor Points: Identify CableAnchor child nodes on the props. If missing, use center + offset. ​Obstacle Avoidance (Advanced): Use Godot's NavigationServer (or a simplified A* Grid) to find a path along walls/floors if snap_to_walls is enabled. ​Simulation: Generate a Curve3D. Apply gravity sag based on slack. ​Bake: Generate the mesh. ​6. API & Contracts ​Interface: ILogicNode ​Any prop participating in the circuit must implement (or wrap):
