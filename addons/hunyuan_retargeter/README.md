# Hunyuan Retargeter Addon for Godot 3

## Purpose

This Godot 3 editor plugin provides a "plug-and-play" solution for importing humanoid FBX models generated by Tencent's Hunyuan3D / Motion-Diffusion (MDM) models. It automatically retargets the source SMPL-based skeleton to the Godot Humanoid standard, making the models game-ready out of the box.

The addon solves several critical issues common with these AI-generated models:
-   **Incorrect Bone Names:** Automatically renames bones from the SMPL/Hunyuan standard to the Godot/Unity standard.
-   **Broken Animations:** Fixes animation tracks that break due to bone renaming.
-   **Incorrect Rest Pose:** Corrects the model's A-Pose or I-Pose to a perfect T-Pose (for arms) and V-Pose (for legs), which is essential for animation retargeting in Godot.
-   **Incorrect Scale:** Fixes models that import at a minuscule scale, preventing physics and precision errors.
-   **Root Motion:** Provides an option to extract root motion from the hip bone's animation.

## Installation

1.  Copy the `addons/hunyuan_retargeter` directory into the `addons/` folder of your Godot 3 project.
2.  Navigate to **Project -> Project Settings -> Plugins**.
3.  Find "Hunyuan Retargeter" in the list and change its status from "Inactive" to "Active".

That's it! The plugin is now installed and will automatically process any FBX files you import.

## Usage

The addon works automatically. When you drop an FBX file into your project's file system, this script will run as part of the import process. You can select the imported FBX file in the FileSystem dock to configure the import options in the Import tab.

### Import Options

When you select the FBX file, you will see the following script variables in the Import tab. These toggles allow you to control the retargeting process for each specific model.

-   **Enable Root Motion** (`true` by default):
    If enabled, this will analyze the hip bone's animation. It separates the horizontal (X/Z) movement into a new animation track on the scene's root node, leaving only the vertical (Y) movement on the hip bone. This is essential for using "root motion" in a `KinematicBody` or other game physics systems.

-   **Fix Animation Tracks** (`true` by default):
    **CRITICAL.** This should almost always be left on. When bones are renamed (e.g., `Pelvis` -> `Hips`), this function finds all animation tracks pointing to the old name and updates them to point to the new name, preventing your animations from being lost.

-   **Force T Pose** (`true` by default):
    Uses a robust, vector-based algorithm to correct the skeleton's rest pose. It aligns the arms horizontally (T-Pose) and the legs vertically (V-Pose), which is required for Godot's animation retargeting systems to work correctly.

-   **Sanitize Scale** (`true` by default):
    Fixes models that import at a tiny scale. It first ensures the scene root has a scale of `(1, 1, 1)`. Then, it calculates the skeleton's height. If the height is too small (less than 0.5 Godot units from hips to head), it scales up the skeleton's bone positions by a factor of 100.

### Technical Note: Order of Operations

For stability and correctness, the script executes its main functions in a specific, hardened order:

1.  **Find Nodes:** Locates the `Skeleton` and `AnimationPlayer`.
2.  **Sanitize Scale:** Corrects the model's scale first to prevent floating-point precision errors in later calculations.
3.  **Rename Bones:** Renames bones according to the standard map.
4.  **Repair Animation Tracks:** Fixes animation paths immediately after renaming.
5.  **Force T-Pose:** Applies the final pose correction.
6.  **Extract Root Motion:** Extracts root motion as the final step.
